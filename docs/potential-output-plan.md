# 潜在产出：独立子 Mod 实施计划

日期：2026-11-19。用户授权在本仓库新子目录开发 CK3「潜在产出」地图视角及商品开关面板，参考上传图片的分组图标布局。产品 `mod_potential_output/`（Potential Output），独立于 MTS 与两个 POD 产品；本次不发布 Workshop，不沿用其他产品的 Workshop ID 或验收结论。

## 玩家合同

- 从地图视角入口切换「潜在产出」，按伯爵领查看其组成地块的可产商品。
- 面板提供商品图标独立开关、全选、清空与分组操作；多选采用并集，只显示所选商品的潜在产出。清空应显示无匹配，不能退回全选。
- 未开发资源也应可见；当前产出与潜在产出不得混称。精确定义以本机 CK3 原版商品及资源接口研究为准，并将依据与限制写入报告。
- 筛选是本地玩家展示状态；不改变税收、建筑、资源分布、AI 或其他角色状态。旧存档应可直接使用；视角关闭后恢复正常地图。
- 实机只使用 `simp_chinese`。版本以框架安装识别后的实际 launcher/build/EXE 为准；初步识别 CK3 1.21.0 Florin / Steam build 26757580。

## 工作包

1. 原版依据：先读框架合同；登记任务总线；只读识别游戏，查商品、潜在资源、地图模式、图标及筛选数据绑定。若需求存在原版数据缺口，及时询问所需商品来源，继续完成不依赖答案的骨架。
2. 垂直实现：创建独立 descriptor、命名空间 `xapo_`、原生地图模式及面板；优先追加，必要覆盖须记录精确原版身份与升级风险。
3. 完整行为：全部可支持商品、分组开关与空集/多选行为；优先复用原版资产，不复制其他游戏素材。
4. 验收交付：使用框架解析、日志、构建与公共受管验收入口。每个验证过的独立包立即英文 commit 并普通 push `origin master`；fetch/rebase，不新建分支。

## 归属

产品脚本、生成数据、界面、专用构建配置与具体验收证据留本仓库。通用地图/GUI 发现、解析或验收能力先查框架；若形成可复用成果，向框架富化，记录来源、验证与能力边界并引用本项目报告。机器路径与私有存档只放忽略的本机配置，不提交。
