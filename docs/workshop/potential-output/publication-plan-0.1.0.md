# 潜在产出 0.1.0 首次工坊发布计划

日期：2026-11-20。用户已明确授权首次发布到 Steam 创意工坊，要求 BBCode 说明入库、真实使用截图上传、关键图片穿插在对应说明段落。创建新的独立物品，禁止更新 MTS、POD 或上游作者条目。

## 发布物料

- 复用已通过 R0011 的 23 文件运行内容；工坊身份、说明与媒体单独管理。
- 真实截图来自本产品 R0011 冻结构建验收，保留来源、原图 SHA、客户区裁剪矩形、压缩参数与最终图片 SHA；只裁去桌面和窗口边框，不改游戏内容。
- 正文介绍潜在产出定义、单项与分类筛选、多选深浅色规则、使用步骤及兼容边界；至少三张截图插在对应段落中。另上传 Steam 图片栏，正文用固定 commit 的直链图片。
- 标题中英可读；简中正文为主，附简明英文说明。版本与语言范围保持实测边界；正文按 Steam BBCode 与 8000 UTF-8 字节上限校验。
- 首发没有既有 Workshop ID。持久化 Create 回执后只继续该 ID，未知回调不重试创建；新的法律协议由所有者处理，不代为接受。

## 验收与收尾

1. 核对源码、实测内容、正式 tag/manifest、全部媒体与 BBCode；准备完成后再临时上线。
2. 通过框架 native MCP、当前账号身份和在线空闲状态检查发布。记录新 ID、内容提交、缩略图与图片栏回执。
3. 匿名回读完整正文、更新说明、公开可见性、图片数量与顺序；下载正文图片和 Steam CDN 图核对内容，检查实际渲染的内嵌图片。
4. 通过 Steam 订阅并从空路径下载该物品；与正式 manifest 精确比较。复用公共 workshop_cache 用例，让 CK3 实际加载 Steam 缓存，确认后正常退出，不重跑业务场景。
5. 恢复 Steam 离线、释放进程与屏幕租约；发布回执和最终说明入库，正常 commit/push master。

机器配置、会话与私有原图只放忽略的 artifacts；对外只提交游戏客户区的截图和可审计媒体清单。初始额外存储预算 D 盘 2 GiB，原验收数据继续引用；发布窗口计入系统盘／数据盘安全余量。通用发布、图片与缓存能力复用框架，产品专用文案与媒体归本仓库；新增通用缺口另记录富化决定。
