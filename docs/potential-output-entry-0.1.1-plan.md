# 潜在产出 0.1.1 入口改造与验收计划

用户已授权施工、自测。最终选择常驻视角栏末尾，并要求不改变原生视角栏，只增加原生风格的独立圆形按钮；此选择覆盖此前“＋”弹出面板方案。

入口通过 scripted_widgets 独立注册，使用屏幕右下角锚点放在原生“＋”下方，32×32，绿色资源图标、MOD 角标，悬停标题“潜在产出（XA MOD）”。不覆盖原生 mapmodes/hud/buttons 文件或相关同名类型；原有三份地图/活动 GUI 覆盖仍须说明兼容边界。

候选版本 0.1.1 绑定本机 CK3 1.21.0.3 / build26785313 的 EXE 和原版输入。保留原有 35 种潜力口径、过滤和评分刷新控制器；面板收起后保留窄标题条，支持展开和退出。单击直接进入，重复进入也应正常；普通活动保持人工规划确认。

验收使用框架公共 prepare/preflight/allocate/run/verify、原 Popen、屏幕 keeper 和 CAS；Steam 离线、本机 CK3 排他、冻结源码。仅简体中文执行实机，另外八语言校验编码、格式和键集。测试旧存档、原生栏和“＋”、悬停、三次单击进入、全套过滤和 0/1/2 深浅色、近景图标、收起展开、退出恢复地图模式、再次进入重置和普通宴会规划，最后在游戏内正常退出。实机失败修订源码后分配新场次，不热改加载输入。

静态只证明结构、表达式回归和打包，不授予实机或发布资格。最终实机及失败记录见 [验收报告](potential-output-entry-0.1.1-report.md)；正式工坊发布独立记录，0.1.0 的发布证据保持历史范围。
