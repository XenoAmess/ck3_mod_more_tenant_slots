# 2026-11-19 已确认的着色验收补充

验收真值为 `County.GetPotentialTradeGoodTypes`，只允许原版县潜力表的 35 种商品。增加核对：全选时 2–6 种潜力的县分档一致；铁单选只有有／无两档；铁和盐多选时 0、1、2 档与县潜力表交集一致；未投产但具有潜力的县必须保留。图例标注“潜力种类数”，不得用现有产量或建筑数替代。

规划器图层候选先做原生冷启动：全图县首府定位、零匹配灰色、至少三种计数的底色实测；失败即保留 RED。最终场必须测试正常活动规划器仍可打开、当前活动／旅行角色的入口门禁、收起面板、退出／Esc 恢复，以及无实际活动创建、无经济值改变。中间诊断热改的 profile 不授正式包通过。
