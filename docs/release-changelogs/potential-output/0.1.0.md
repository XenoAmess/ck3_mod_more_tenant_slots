# Potential Output (XA) 0.1.0

Published 2026-11-20: [Workshop 3842767123](https://steamcommunity.com/sharedfiles/filedetails/?id=3842767123).

Adds a county potential-goods view, including undeveloped resources, with 35 individual goods, category toggles, select all, clear, and a collapsible panel. County shading and counts use the number of selected potential kinds, not production or reserves. Exit restores the previous map view; re-entry resets all goods.

The release includes four actual gameplay images in both the Workshop gallery and the illustrated description. The initial Chinese title encoding error was repaired on the same item and verified publicly. Description BBCode and complete bilingual Change Notes are committed.

Source gameplay/old-save acceptance applies to CK3 1.21.0 build26757580. The actual downloaded 23-file cache matched the tagged release and loaded through the common menu-only case on 1.21.0.3 build26785313; normal GUI quit, original exit0, lease release and Steam offline passed. This cache result does not extend gameplay qualification to the hotfix build. Existing map-object diagnostic and GUI compatibility limits remain documented.
